# UNIDAD-1-EJERCICIO-12
Resolución del ejercicio N°12 de la unidad 1 de programación 2.
Este programa realiza el control de calidad y validación de piezas industriales mediante inspección dimensional. 
En términos generales, se encarga de registrar las dimensiones reales y de referencia de un lote de piezas (asegurando que sus medidas sean físicamente válidas), evaluar automáticamente si cada producto cumple con los márgenes de tolerancia de fabricación permitidos.
Además de presentar en pantalla los resultados del control técnico.
